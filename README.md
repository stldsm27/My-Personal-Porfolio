# Sarah Ledesma's Personal Portfolio

This is my personal portfolio website showcasing my background, hobbies and interests, and contact information.

## How to Run Locally
Open `index.html` in a browser to view the website.

## Features
- About Me page
- My Hobbies & Interests and a Fun Fact section with image carousel
- Contact information page
